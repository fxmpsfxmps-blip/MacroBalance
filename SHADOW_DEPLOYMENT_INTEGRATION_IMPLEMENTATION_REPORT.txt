Architecture
Calculator calcular() starts the unchanged synchronous Production calculation and invokes one guarded, non-awaited raw hook before Production parsing. With valid future flags only, a minimized snapshot is deferred to POST /api/shadow-evaluate. The server independently enforces flags, kill switch, sample, origin, content type/size, Firebase ID-token verification, keyed UID pseudonymization, semantic mapping, frozen PATCH3 hash verification, validated harness execution, isolated storage, and stop processing. The browser receives only a 202 receipt, never PATCH3 nutrition output.

Raw hook and missingness
DOM values are captured synchronously before Production normalization. Field state distinguishes PRESENT, EMPTY, MISSING_ELEMENT, and NOT_APPLICABLE; null and explicit zero remain values. The mapper maps only semantic equivalents. Missing/ambiguous training never becomes NONE/0/0/LOW. Mapping provenance, missingFields, contradictions from PATCH3, reason codes, and valuesImputed=false remain auditable.

Flags
Client=false; server=false; kill=true; sample=0 by default. Invalid/missing configuration is OFF. Kill wins; server is independently authoritative; zero sample prevents execution. Required server prerequisites keep execution disabled when absent.

Authentication and pseudonymization
Firebase ID tokens are verified against Google secure-token JWKS with exact issuer/audience and RS256. Browser UID is never trusted. A stable, versioned HMAC-SHA256 pseudonym uses a server-only secret of at least 32 characters. Token and raw UID have no persistence path.

Frozen Candidate and harness
Freeze MB_CANDIDATE_V1_PATCH3_L005_INPUT_CONTRACT_STABILIZATION_2026-08-28, parent PATCH2, 28 exact files. Every execution verifies the manifest; mismatch stops shadow without fallback. Harness version/hash are surfaced in protected health metadata. Vendored scientific and harness files were not edited.

Datastore/retention/alerts
No Production datastore fallback exists. A separate HTTPS adapter requires a non-Production project/path and token. macrobalance-502bb, users, and goals_history trigger refusal. Local absent infrastructure is DATASTORE_NOT_CONFIGURED and execution remains OFF. Retention is explicitly PROPOSED_OPERATIONAL_POLICY with raw 7d, result 30d, aggregate 90d, alerts incident closure + approved audit window. Critical stops are isolated; alert/control failures cannot escape.

Health/security
Protected health returns operational metadata only. Static tripwire bans menu-engine, firebase-init, or calculator authority imports. Client excludes PII, UID, water/free text, menus, history, and goals. Server secrets are not emitted into dist.

Rollback
Set kill=true, client/server=false, sample=0. Production is independent and never awaits shadow. Code rollback removes the guarded hook, script tags, endpoints, and shadow-only files.
